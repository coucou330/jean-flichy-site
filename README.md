# jean-flichy-site

Personal website of Jean Flichy — https://coucou330.github.io/jean-flichy-site/

Static site generated by a small Python script (`build.py`, Jinja2 + Markdown + PyYAML) and served by GitHub Pages from `main:/docs`. No JavaScript framework; the site works without JavaScript.

## Edit the site in 3 commands

1. Edit a page in `content/` (Markdown with a YAML header) — e.g. `content/about.md`.
2. `python build.py` (first time only: `pip install -r requirements.txt`).
3. `git add -A && git commit -m "Update about page" && git push` — the site is live 1–2 minutes later.

## Layout

| Path | What it is |
|---|---|
| `site.yml` | Title, address (`origin` + `base_url`), e-mail, LinkedIn, navigation |
| `content/` | One `.md` file per page. `index.md` = home, `work/index.md` = list of projects, `work/<slug>.md` = a project |
| `content/work/_template.md` | Copy it to add a project (files starting with `_` are never published; `draft: true` hides a page) |
| `templates/` | `base`, `home`, `page`, `work`, `project` (Jinja2) + `partials/` (`card`, `path`) |
| `data/` | Shared data in YAML — `path.yml` is the "Path" timeline shown on the home and About pages |
| `static/` | CSS, self-hosted fonts (Inter, Source Serif 4 — SIL OFL), images, favicon — copied as is into `docs/` |
| `docs/` | **Generated** — do not edit by hand |

Notes:
- Projects: one file per project in `content/work/` (`order`, `card_summary`, `year`, `filters` drive the cards on the home and Work pages). Short projects are the `more:` list in `content/work/index.md`.
- Work filters (Energy · Robotics · Leadership · Research) work without JavaScript (`#energy` anchors + CSS `:target`); a small inline script avoids the jump and announces the count.
- `[[include:path]]` alone on a line in Markdown inserts `templates/partials/path.html`.
- `<!-- comments -->` in Markdown are internal notes (sources, facts to confirm): `build.py` strips them, they never reach the published HTML.
- Root-relative links (`/work/`) are prefixed with `base_url`, so the same source works under `/jean-flichy-site/` and at the root of a custom domain. For a custom domain: set `origin`, set `base_url: ""`, add `cname: www.example.com` to `site.yml`, rebuild.
- Local preview: `BASE_URL= python build.py && python -m http.server -d docs` → http://localhost:8000 (rebuild without `BASE_URL=` before pushing).
